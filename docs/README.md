# Documentation

One line per document. Overview and results: [`../README.md`](../README.md).

- [`DATASET.md`](DATASET.md) — dataset card: the ten synthetic cases, how they were generated and revised, the response export, the earlier pilots and the licensing status. Read it before reusing an image or a response.
- [`LIMITATIONS.md`](LIMITATIONS.md) — what the results support and what they do not, design limits and the next useful experiments. Read it before quoting a result.
- [`METHODOLOGY.md`](METHODOLOGY.md) — question, request protocol, ground truth, scoring, timing and cost, and publication checks. Read it before replaying a request or changing the scoring.
- [`REPRODUCIBILITY.md`](REPRODUCIBILITY.md) — which parts reproduce offline, what a paid replay guarantees and how scoring stays compatible. Read it before rescoring, rebuilding figures or replaying.
- [`RESEARCH.md`](RESEARCH.md) — research background on recognition, layout, OCR-free approaches, degradation and monetary risk. Read it for the reasoning behind what the lab measures.
- [`SHARE.md`](SHARE.md) — the short X post that announces the repository, with its suggested attachment. Read it when sharing the lab.
