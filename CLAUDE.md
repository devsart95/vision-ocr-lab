# Vision OCR Lab

Public exploratory research artifact; project magnitude is declared in project.yaml.

- Offline analysis reads the archived PNGs, manifests and allowlisted responses. Preserve the original primary dataset and audit trail.
- The scoring policy lives in the domain module. Monetary aggregation uses Decimal. A separator that changes numeric meaning is an error.
- Keep primary synthetic results separate from private-image pilot aggregates and unscored collection templates.
- API replay is a separate explicit paid command using an environment credential. The default analysis and validation commands stay offline.
- Before publication, run make check and review image content. Never add private inputs, credentials, encrypted provider reasoning or local-machine paths.
- Research claims and documentation are in English. Experimental Spanish prompts/labels are preserved for fidelity.
